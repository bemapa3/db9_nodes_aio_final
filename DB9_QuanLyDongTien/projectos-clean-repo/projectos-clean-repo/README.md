# ProjectOS Clean Repo

## Run

```bash
cp .env.example .env
npm install
npm run setup
npm run dev
```

Open http://localhost:3000

This repo includes:
- dark red ProjectOS UI
- Prisma + SQLite
- companies, projects, engagements
- dashboard summary
- gantt drag reschedule via API
- AI assistant with action preview
- backup targets / policies / runs
