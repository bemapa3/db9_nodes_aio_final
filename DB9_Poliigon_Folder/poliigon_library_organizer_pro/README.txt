Poliigon Library Organizer PRO

Run from source:
1. pip install -r requirements.txt
2. python app.py

Windows EXE build:
- First time: double click build_exe.bat
- Later builds: double click build_exe_noinstall.bat

Notes:
- Config, rules, and tags are saved next to the app.
- Long organize and reorganize jobs now run in the background and update progress in the UI.
